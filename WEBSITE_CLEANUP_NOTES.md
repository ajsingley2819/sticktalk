## How to Add More Articles

### To add a golf article:
1. Create your HTML file in the `articles/` folder
2. Use the same header/footer structure as `sample-golf.html`
3. List it in `articles/strokologist-articles.html` JavaScript

### To add a hockey article:
1. Create your HTML file in the `articles/` folder  
2. Use the same header/footer structure as `sample-hockey.html`
3. List it in `articles/puckfessor-articles.html` JavaScript
